Projeto da PCB
==================================

A partir do projeto da etapa 2, alguns ajustes foram feitos no esquemático como por exemplo a inserção de reguladores lineares, capacitores e mudança de alguns pinos de IO. 

Para acessar o projeto deve ser ter o KiCAD 10.0.1 ou mais recente. Após isso deve seguir as seguintes instruções:

* Baixar o arquivo `"Altimetro_para_Foguetes_rev2_comapact.zip" <etapa_3/PCB/Altimetro_para_Foguetes_rev2_compact.zip>`_
* Na barra esquerda clicar "Desarquivar Projeto" e selecionar o arquivo Altimetro_para_Foguetes_rev2_comapact.zip
* Abrir o projeto da PCB e/ou esquemático
